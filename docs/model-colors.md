# 模型配色规则

<!-- 记述当前有效的配色事实、约束与已知限制，不写实现过程。 -->

## 规则

- 颜色绑定模型业务键 `model`（`BreakdownRow.key`、`TimeseriesRow.model`、`RequestRow.model` 共用），**不绑定展示名**；展示名规范化或追加 `(标识)` 后缀不影响颜色。
- 基础色相按系列分配：名字同系列的模型颜色相近，系列内用深浅档位区分；不同系列色相拉开。
- 颜色只由标识本身与静态色表决定，与筛选、时间、tab、刷新次数、其它模型是否存在无关；首帧即稳定，不需要为配色额外请求模型集合。
- 色点出现在趋势图系列与图例、按模型拆分、模型下拉、请求明细，全部取自 `src/web/model-colors.ts` 的 `modelColor()`，与图表系列填充色逐值一致。

## 系列前缀表

系列按标识前缀判定，取**最长匹配**：`minimax`、`deepseek`、`kimi`、`mimo`、`step`、`glm`、`hy`。`hy` 用短前缀，使 `hy3`、`hy4` 与 `hy4-*` 变体同属一个系列；`mimo` 与 `minimax` 靠最长匹配区分。前缀表只增不改，不根据展示名、厂商或模型语义推断。

## 兜底与档位

- 每个系列除显式项外保留 3 个静态档位；hunyuan 有 5 个显式项，合计 8 档。
- 色表外的标识若命中系列前缀，用稳定哈希从该系列的保留档位取一档；未命中任何前缀，则从全局兜底色板取色。保留档位清单来自静态色表，不随数据集合变化。
- 哈希为 FNV-1a 32 位（`hashKey()`），**参数与取模方式冻结**：改动会让所有走兜底的模型集体换色。`tests/model-colors.test.ts` 固化了若干输出。
- 色值全部是十六进制字面量，运行时不做 HSL 换算，保证跨浏览器与跨视图逐值一致。

## 维护约束

- **显式色表只增不改**：以后新增模型只允许追加条目，不得重排或改动已有色值。确需改色时必须在本文件记录原因与生效版本，因为它会破坏该模型的长期识别。
- 新增标识若命中系列前缀会自动落进该系列色系，无需改代码；若希望它使用特定颜色，追加到显式色表并同步更新本文件表格与一致性单测。
- 哈希算法、前缀表与取模方式的变更视同破坏性变更，需先评估对所有兜底模型颜色的影响。

## 已知限制

- 同系列颜色相近，堆叠图相邻块靠 1px 白色描边分辨边界；浅色档在白底偏淡。
- 每系列只有 3 个保留档位，多个同系列新模型可能哈希到同一档而同色；当前不扩容，后续按实际模型规模再评估。
- 两个色表外标识恰好落到同一基础色且同一档位时允许同色。
- 全局兜底色板与部分系列色相可能接近，靠深浅档位拉开。
