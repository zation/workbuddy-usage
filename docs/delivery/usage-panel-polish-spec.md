# 面板可读性优化 Spec

## 背景与目标

v1.0.0 已交付，面板把 Token 与积分上下平铺为两个模块。实测首屏信息密度过高：两个模块各有一张全量请求明细表（约 900 行）、三个拆分列表带内部滚动条、token 大数字用完整千分位、模型维表中 `hy4` 与 `hy4-free` 规范化后同名、部分模型在某一指标上恒为 0 却仍占据图例与列表项，同时缺少缓存命中率与数据新鲜度。此外，「下钻」与「筛选」实际写的是同一份状态，却各有一套 UI（会话明细横幅、筛选标签），形成重复表达。

本交付在**不改变统计口径**的前提下重整信息架构与数值呈现：状态只有一份筛选，首屏一屏可读，数值易读，重复 UI 移除。

## 与初始需求的关系

本 Spec 的需求**直接覆盖** v1.0.0 `usage-stats-spec.md` 中的行为 1（两模块结构）、行为 5（图表堆叠仍按模型着色）、行为 6（列表点击的独立状态）、行为 7（明细默认排序）、AC11（界面结构），以及 `product-brief.md` 范围段和成功标准中「逐层查看」那条的措辞。归档的 v1.0.0 三份文档不改写；长期文档按本 Spec 更新：`product-brief.md`（范围与成功标准）、`technical-architecture.md`（面板层描述、`/api/summary` 接口表、关键依赖表中「端点随…增加」的措辞）、`data-model.md`（模型展示名规则 C12、`schema_version`）、`devops.md` 无需改动。

## 范围与非目标

**范围**

- 界面结构改为 Token / 积分两个 tab，共用一组筛选栏。
- 收敛为「只保留筛选」：列表点击与下拉框选择是同一动作的两个入口；移除会话明细横幅、筛选标签（chips）与滚动跳转。
- 三个拆分列表固定行数、固定行高、无内部滚动条。
- 两张请求明细表默认折叠、默认时间降序、折叠状态独立、折叠时不请求明细数据。
- token 数值改用 K / M / B 单位。
- Token 模块「缓存命中」指标卡同时显示比率。
- 按当前 tab 主指标隐藏 0 值模型。
- 模型展示名冲突时保留两个业务键并改名区分。
- `/api/summary` 返回 `lastRefreshAt`，刷新按钮前显示上次刷新完成时间。

**非目标**

- 不改变统计口径：C2 取最大值归并、C6 积分挂接、R8 覆盖率、R13 维度一致性全部保持；0 值隐藏与列表截断只作用于展示层。
- 不做分组归一化（另见 `group-normalization-spec.md`）。
- 不处理子代理积分（见 `docs/backlog/subagent-credit-reconciliation.md`）。
- 不做缓存命中率按天趋势，不做「命中率是否随使用改善」的分析。
- 不做「显示更多」、分页、虚拟滚动，不保留数值精确值或 hover 提示。
- 不新增筛选维度、筛选开关或排除开关；不新增下钻、跳转、悬浮层等独立交互状态。
- 不改 `~/.workbuddy` 下任何原始数据，不新增外部数据源。

## 用户或系统行为

1. **筛选状态唯一**：时间、分组、对话、模型四个条件只有一份状态，入口只有筛选栏下拉框与拆分列表点击两处，两者写入同一个 `filters`，效果完全一致。当前值由下拉框自身显示；清除通过下拉框的「全部…」选项或「重置」按钮。不再有筛选标签、会话明细横幅、点击后的滚动跳转，也不再有「下钻」这一独立概念与状态。
2. **Tab**：筛选栏下方为 Token / 积分两个 tab，默认激活 Token。切换 tab 保留筛选条件、时间预设、明细折叠状态与排序状态；只渲染激活 tab 的内容。
3. **列表点击**：点击「按分组 / 按对话 / 按模型」中的某项，即把该维度筛选设为该项业务键；该列表自身也参与筛选，点击后只显示被选中项，与其它视图一致。
4. **拆分列表**：每个列表最多显示 8 行，每行高度固定，容器高度 = 8 × 行高，不出现内部滚动条；超出的行不渲染，不提供展开入口。占比分母仍为服务端返回的全量合计，面板头部的「N 项」显示全量项数。
5. **请求明细**：两个模块各一张表，默认均折叠、折叠状态互相独立；默认按时间降序（最新在前）。点击面板标题栏展开 / 收起，展开后仍可点表头切换排序。折叠状态下不发起 `/api/requests` 请求。
6. **数值格式**：所有 token 数值用 K / M / B 缩写；积分保持两位小数；请求数、会话数、条数保持整数。
7. **缓存命中**：Token 模块「缓存命中」指标卡的数值旁同时显示命中比率。
8. **0 值隐藏**：按当前激活 tab 的主指标过滤模型维度的展示。
9. **重名模型**：`hy4` 与 `hy4-free` 保留为两个业务键，展示名可区分。
10. **刷新时间**：「刷新数据」按钮前显示上次刷新完成时间；刷新成功后自动更新。
11. **刷新**：触发一次刷新并展示扫描文件数、更新请求数、补挂积分条数与耗时，行为不变。

## 业务规则

**R1 筛选唯一（覆盖 v1 行为 6）**
移除 `drill()`、`detailSession`、`detail-banner`、`ActiveChip` 与 `scrollIntoView`。列表点击与下拉框 `onChange` 走同一个 `patchFilters` 路径。筛选条件仍只有时间、分组、对话、模型四项，之间为逻辑与；维度值一律用业务键字符串。

**R2 Tab 与状态保持**
默认激活 Token。tab 切换不得重置 `filters`、`preset`、`custom`、两张表的折叠状态与排序状态。未激活 tab 不挂载 DOM，避免 ECharts 在零尺寸容器中初始化；现有 `EChart` 的 `ResizeObserver` 保持不变，挂载时按容器尺寸渲染。筛选为两个 tab 共用，切换后所有视图按同一 `filters` 呈现。

**R3 固定行数**
三个拆分列表统一最多 8 行，行高固定，容器高度按 `8 × 行高` 计算；移除 `.breakdown-list` 的 `max-height` 与 `overflow: auto`。排序仍在服务端完成，前端只截取前 8 行。`tokenShare` / `creditShare` 与「N 项」均按全量结果计算，不随截断改变。被截断的项仍可通过筛选下拉选中。

**R4 明细折叠、排序与懒加载**
两张表各持一份折叠状态，默认折叠。默认排序为 `startedAt` 降序（覆盖 v1 行为 7 的「各模块按主指标降序」）。展开 / 收起控件位于面板标题栏，需带 `aria-expanded`。折叠时明细请求路径为 `null`，`useQuery` 不发起请求；展开后按当前排序请求一次，表头切换排序沿用现有 API 排序。展开后表格保留 440px 内部滚动区，避免长表格把页面撑得过长。

**R5 K / M / B 单位**
仅用于 token 数值（指标卡、拆分列表、明细表 token 列、tooltip、趋势图 y 轴）：`≥10³` 用 K、`≥10⁶` 用 M、`≥10⁹` 用 B，保留 1 位小数，小于 10³ 显示整数。不提供精确值、不在 `title` 或 hover 中保留千分位原值。趋势图 y 轴现有的「万 / 亿」一并替换。积分不改用 K / M，保持 `formatCredit` 两位小数，趋势图积分 y 轴现有的 `1.0k` 去掉。请求数、会话数、条数等非 token 计数保持整数千分位。

**R6 缓存命中比率**
在 Token 模块「缓存命中」指标卡数值旁显示比率，口径为 `cacheReadTokens / inputTokens`（C4 保证缓存是输入的子集）。`inputTokens = 0` 时显示 `—`。比率使用现有 `formatPercent`（保留 1 位小数）。积分模块不显示该比率，不新增趋势序列。

**R7 0 值隐藏（展示层规则）**
按当前激活 tab 的主指标判断：Token tab 过滤 `totalTokens === 0` 的模型，积分 tab 过滤 `credit === 0` 的模型。过滤同时作用于趋势图系列（含图例）、按模型拆分列表、模型筛选下拉项。按分组、按对话两个维度不受此规则影响；请求级明细表不按模型过滤，仍展示筛选下的全部请求。不显示「已隐藏 N 项」一类的提示。过滤不改变任何聚合值：被隐藏行的指标为 0，各维度之和仍等于总览合计（R13）。**R7 优先于 R8**：先过滤，再对仍可见的项应用展示名。

**R8 模型展示名冲突**
保留 `hy4` 与 `hy4-free` 两个 `model` 业务键，不合并统计、不改着色与筛选行为。在 `data-model.md` C12 的规范化之后增加一步冲突处理：按 `model` 字典序，冲突组内第一项保留规范化展示名，其余显示 `规范化名 (model 标识)`，当前结果即 `Hy4` 与 `Hy4 (hy4-free)`。规则只依赖标识集合，与文件遍历顺序无关。展示名规则变化需递增 `schema_version` 触发派生库重建，避免旧索引保留旧名字。

**R9 刷新完成时间**
`SummaryResponse` 增加 `lastRefreshAt: number | null`，`getSummary` 从 `meta.last_refresh_at` 读取；该字段与筛选条件无关。面板在「刷新数据」按钮前显示本地时间 `HH:mm`，为 `null` 时显示「尚未刷新」。刷新成功后随现有 `version` 依赖重新取 `/api/summary`，显示自动更新。`technical-architecture.md` 接口表同步补充该返回值。

**R10 口径不变与分层**
面板只渲染 API 返回值，不自行求和或换算（AD-4）；筛选值仍从 API 提供的业务键取。除 R9 的只读字段外，服务层聚合 SQL 不变；除 R8 的维表展示名规则外，解析层不变。

## 边界情况

| 情况 | 处理 |
| --- | --- |
| 点击拆分列表某项后该列表只剩一项 | 符合「筛选」语义；通过下拉框「全部…」或「重置」恢复，不额外提供清除标签 |
| 拆分列表结果少于 8 行 | 容器按实际行数收缩，不留空白占位 |
| 某维度全量结果为 0 行 | 显示现有空态文案，容器高度按空态渲染 |
| 两个 tab 的明细折叠状态不同 | 各自独立保存，切换 tab 不互相覆盖 |
| 明细折叠期间筛选条件变化 | 不请求明细；展开时按最新筛选条件请求 |
| 展开表格后行数超过 440px | 保留表格内部滚动，页面本身不因表格产生第二套滚动 |
| 模型在当前 tab 指标为 0、另一 tab 非 0 | 只在当前 tab 隐藏；切换 tab 后按新主指标重新判断 |
| 隐藏后某 tab 下所有模型都为 0 | 趋势图与按模型列表显示空态，不报错 |
| 展示名冲突组中被隐藏一项 | 仍按 R8 固定确定展示名，不随 tab 或筛选动态改名 |
| `inputTokens = 0` | 缓存命中比率显示 `—` |
| `lastRefreshAt` 为 `null` | 显示「尚未刷新」，不显示占位时间戳 |
| 刷新失败 | 刷新时间保持上一次成功值，错误信息仍由现有刷新提示条呈现 |

## 验收标准

- **AC1 筛选唯一**：界面不存在筛选标签、会话明细横幅与点击后的滚动跳转；下拉框选择与列表点击写入同一份筛选状态，两者结果一致；清除筛选只能得到初始状态。
- **AC2 Tab**：首屏默认激活 Token tab；切换后筛选条件、时间预设、两张表的折叠与排序状态均保持不变；两个 tab 的图表在首次激活时能正常渲染且尺寸正确。
- **AC3 拆分列表**：三个列表各最多 8 行、行高固定、无内部滚动条；「N 项」为全量项数；占比分母为全量；被截断项仍可从筛选下拉选中。
- **AC4 明细**：两张表默认折叠且状态独立；默认时间降序；折叠时网络请求中不含 `/api/requests`；展开后表头排序可用。
- **AC5 单位**：token 数值按 K / M / B 显示（含趋势图 y 轴），无精确值 hover；积分与请求数等计数格式不变，趋势图不再出现「万 / 亿」与积分 `k`。
- **AC6 命中率**：Token 指标卡显示 `缓存命中 / 输入` 的比率，与按 R6 手算一致；输入为 0 时显示 `—`；无按天趋势。
- **AC7 0 值隐藏**：Token tab 不出现 `totalTokens = 0` 的模型系列、拆分行与下拉项，积分 tab 不出现 `credit = 0` 的；`hy4-preview-f` 在 Token tab 隐藏、在积分 tab 因有积分而保留；无任何提示说明。
- **AC8 重名模型**：`hy4` 与 `hy4-free` 仍为两个可分别筛选的业务键，展示名可区分且与刷新次数、文件遍历顺序无关；派生库重建后结果一致。
- **AC9 刷新时间**：首屏即显示上次刷新完成时间；触发刷新后显示值更新为本次完成时间；无刷新记录时显示「尚未刷新」。
- **AC10 一致性**：在「全部时间 + 无筛选」下，应用 0 值隐藏与列表截断后，各维度拆分指标之和仍等于总览合计（v1 AC3 口径）。
- **AC11 回归**：v1.0.0 的 AC1–AC10 中除被本 Spec 显式覆盖的界面结构项外，其余全部继续通过；`npm run typecheck`、`npm test`、`npm run build` 通过。

## 已确认决策

- 只保留「筛选」概念，移除下钻及其重复 UI；列表点击是筛选的另一入口。
- 筛选标签（chips）移除，当前筛选值由下拉框自身表达。
- 取消「点对话自动展开明细」：明细默认折叠，由用户自行展开。
- 拆分列表统一 8 行，超出直接不渲染，不提供「显示更多」。
- 明细默认时间降序，折叠状态两表独立，折叠时不发请求。
- K / M / B 保留 1 位小数、不保留精确值；积分与计数不改用缩写单位。
- 缓存命中比率分母取 `inputTokens`，不做按天趋势。
- 0 值隐藏按当前 tab 主指标，作用于趋势图、按模型拆分与模型下拉，明细表不受影响，不加提示。
- 重名模型保留两个业务键，展示名冲突时按字典序给非首项追加 `(model 标识)`。
- 刷新时间取「上次刷新完成时间」，挂在 `/api/summary`。
